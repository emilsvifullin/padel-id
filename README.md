# Padel ID

Визуальная основа приложения для iPhone на SwiftUI. В проекте есть главный экран, фирменные компоненты и настройки оформления с выбором темы и иконки.

## Локальный запуск

1. Откройте [PadelID.xcodeproj](ios/PadelID.xcodeproj) в Xcode.
2. Выберите схему **PadelID** и симулятор iPhone с iOS 26 или новее.
3. Нажмите **⌘R**. После изменения файлов нажмите **⌘R** ещё раз.

Для запуска достаточно Xcode и установленного симулятора iOS.
