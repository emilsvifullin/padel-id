# Padel ID

Padel ID — паспорт падел-игрока для iPhone. Объективный уровень по шкале 0–7 с
надёжностью, понятной историей изменений и объяснением каждого пересчёта;
Padel DNA — профиль стиля игры по шести направлениям; матчи 2×2, которые
подтверждают все четыре участника; поиск игроков и совместимость партнёров;
навыки, подтверждённые тренерами.

Приложение полностью на русском языке, нативное (SwiftUI, iOS 26, Liquid Glass),
работает с плохой сетью и без неё (кэш, очередь неотправленных действий).

## Установка на iPhone

Сборка распространяется как `PadelID.ipa` без платного аккаунта разработчика —
через [SideStore](https://sidestore.io) или iLoader, которые подписывают
приложение вашим Apple ID при установке.

1. Откройте последний релиз в разделе **Releases** этого репозитория и скачайте
   `PadelID.ipa` (рядом лежит `PadelID.ipa.sha256` для проверки).
   Та же сборка доступна как артефакт `PadelID.ipa` в успешном запуске
   workflow **Release**.
2. В SideStore: вкладка **My Apps** → **+** → выберите `PadelID.ipa`.
   В iLoader: выберите файл и устройство и нажмите установку.
3. С бесплатным Apple ID приложение нужно обновлять в SideStore раз в 7 дней;
   данные при этом сохраняются.

Это самостоятельная release-сборка: она работает напрямую с продакшен-API
`https://padel-id-gamma.vercel.app`, не требует Metro, Expo Go, локального
сервера или прямого доступа к Supabase.

## Возможности

- **Аккаунт:** регистрация по почте и паролю, вход, ключ восстановления вместо
  письма, смена пароля и почты, выход на всех устройствах, удаление аккаунта.
- **Профиль:** имя, @username, город и клуб, сторона корта, ведущая рука, фото,
  видимость в поиске.
- **Рейтинг 0–7:** стартовая калибровка по анкете, пересчёт после каждого
  подтверждённого рейтингового матча с учётом партнёра, обоих соперников,
  неопределённости, ожидаемого и фактического результата, разницы в счёте и
  защиты от «фарма». Каждое изменение объясняется.
- **Padel DNA:** подача и приём, защита, переход и свеча, игра у сетки, удары
  над головой, стабильность и решения — из самооценки, отзывов партнёров и
  соперников, оценок подтверждённых тренеров и результатов упорных сетов, с
  уровнем доверия по каждому направлению.
- **Матчи 2×2:** товарищеские и рейтинговые, проверка счёта по правилам падела
  (сеты, тай-брейки, супертай-брейк), подтверждение всеми участниками, спор с
  причиной, защита от дублей, повторных подтверждений и одновременных правок.
- **Друзья:** взаимные заявки, входящие и исходящие, отмена и удаление; друзья доступны при выборе состава.
- **Предстоящие игры:** открытые места, автоматический допуск по надёжному рейтингу или решение организатора, отмена участия и переход к счёту с четырьмя подтверждениями.
- **Игроки:** поиск по имени и @username с фильтрами (город, клуб, диапазон
  уровня, сторона, только надёжный рейтинг, только тренеры) и сортировкой по
  совместимости, уровню или активности; профили, совместимость партнёров с
  объяснением, история совместных игр.
- **Анализ:** уровень и история, диаграмма или численные показатели DNA, последние десять подтверждённых матчей и полная текущая серия; тренд, сравнение с ожиданиями, стороны корта, упорные сеты,
  лучший партнёр, зона роста — только на реальных данных.
- **Тренеры:** заявка на верификацию, оценка навыков игроков, модерация заявок.

## Архитектура

```
ios/        приложение SwiftUI (XcodeGen), unit- и UI-тесты
server/     публичный API на Vercel (Hono + zod), тесты и e2e
supabase/   миграции Postgres, Edge Function account, тесты БД
scripts/    тестовые утилиты, генерация фикстур и иконки, CI-скрипты
docs/       ios-architecture.md — контракты клиента; backend.md — бэкенд и эксплуатация
```

Приложение обращается только к API на Vercel. Ключ service role хранится
исключительно в окружении Supabase Edge Function; в приложении, репозитории,
логах и релизной сборке секретов нет. Подробности — в
[`docs/backend.md`](docs/backend.md) и [`docs/ios-architecture.md`](docs/ios-architecture.md).

## Разработка

| Что | Как |
| --- | --- |
| Тесты БД | `scripts/db/run-tests.sh` (локальный PostgreSQL) |
| API | `cd server && pnpm install && pnpm test` |
| E2E API | локальный стек Supabase CLI, затем `pnpm test:e2e` (см. `.github/workflows/backend.yml`) |
| iOS | `cd ios && xcodegen generate`, затем схема `PadelID` в Xcode 26 |

## CI/CD

- `backend.yml` — тесты БД, линтер схемы, unit-тесты API и e2e на локальном стеке Supabase.
- `production-smoke.yml` — ежедневная проверка продакшен-API.
- `ios.yml` — сборка, unit- и UI-тесты на четырёх конфигурациях симулятора
  (размеры экранов, светлая и тёмная темы, крупный шрифт) со скриншотами.
- `release.yml` — release-архив, упаковка и проверка `PadelID.ipa`, публикация релиза.

Навигация версии1.1: **Главная · Матчи · Анализ · Друзья · Профиль**. Вкладки постоянно доступны. Главная показывает ближайшую игру с вашим участием, профиль содержит все настройки аккаунта.

Порядок совместимой поставки, проверка прав администратора, установка и проверки на реальном iPhone: [`docs/release-1.1.0.md`](docs/release-1.1.0.md). Фактическое состояние разработки и проверки: [`HANDOFF.md`](HANDOFF.md).
