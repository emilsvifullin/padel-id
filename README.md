# Tennis ID

Приложение для iPhone на SwiftUI. Схема `PadelID` открывает серверную авторизацию и анкету. Схема `Tennis ID - Проверка` открывает локальные сценарии кабинета игрока.

## Локальный запуск

1. Откройте [PadelID.xcodeproj](ios/PadelID.xcodeproj) в Xcode.
2. Выберите схему **PadelID** и симулятор **iPhone 17 Pro Max** с iOS 26 или новее. Это текущая модель для разработки и проверки.
3. Нажмите **⌘R**. После изменения файлов нажмите **⌘R** ещё раз.

Для запуска достаточно Xcode и установленного симулятора iOS.

## Сборка для проверки на iPhone

Выберите схему **Tennis ID - Проверка**. Через троеточие доступны сценарии входа, анкеты, покупки и продления. Пункт **Кабинет игрока** открывает расписание, абонемент и настройки. В настройках доступны профиль, уведомления и чат поддержки. Чат, профиль, настройки уведомлений и подтверждение платежей работают с локальными данными.

Для установки из Xcode выберите подключённый iPhone и нажмите **⌘R**. Для IPA выберите **Product → Archive** и экспортируйте архив с подписью для нужного iPhone. На экране «Домой» приложение называется **Tennis ID**. Для сборки с серверной авторизацией используйте схему **PadelID**. Поддержку сценариев и условия выпуска см. в [материалах приёмки](docs/ios-release-qa.md).
