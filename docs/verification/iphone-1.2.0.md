# Padel ID 1.2.0 — проверка на вашем iPhone

Выполнять после установки версии 1.2.0, сборки 3, и совместимого обновления
сервера. Сейчас кандидат не опубликован, а доступ через МегаФон без VPN
не подтверждён. Этот документ описывает ожидаемые результаты, а не состоявшуюся
приёмку. Подпись при установке через SideStore/iLoader не подтверждает работу push.

Запишите дату, версию iOS, способ установки и результаты. Используйте свой
существующий аккаунт; для переписки и совместных событий понадобится второй
участник. Не удаляйте основной аккаунт ради проверки.

## Иконки и оформление

1. После первой установки откройте домашний экран: иконка Padel ID должна иметь
   ярко-зелёный фон. При обновлении уже выбранная альтернативная иконка может
   сохраняться — сначала выберите «Лайм» в приложении.
2. Откройте **Профиль → Оформление**. Выберите **Графит**, вернитесь на домашний
   экран и убедитесь, что изменилась настоящая иконка Padel ID.
3. Повторите с **Мячом**, затем с **Лаймом**. Галочка в приложении должна
   соответствовать иконке на домашнем экране.
4. Полностью закройте Padel ID и откройте снова. Выбор иконки должен сохраниться.
5. Проверьте доступные системные варианты оформления домашних иконок iPhone.
   Padel ID должен оставаться узнаваемым; выбор дизайна в приложении должен
   соответствовать системной иконке после возвращения в приложение.
6. В «Оформлении» по очереди выберите **Светлая**, **Тёмная** и **Автоматически**.
   Проверьте все пять вкладок, открытые окна и клавиатуру. В автоматическом
   режиме приложение должно следовать теме iPhone. После перезапуска выбор
   должен сохраниться.

## Данные и основные действия

1. Войдите в прежний аккаунт. Имя, рейтинг, история подтверждённых матчей и
   настройки должны сохраниться. Установка обновления не должна создавать
   новый профиль вместо существующего.
2. Откройте игрока, игру, клуб и переписку; вернитесь назад. Исходный экран и
   его контекст должны сохраниться.
3. Отправьте сообщение второму участнику и получите ответ. Проверьте клубную
   новость, комментарий и реакцию. При отказе сервера приложение должно
   показывать ошибку, сохраняя введённый текст.
4. Откройте **Мои тренировки и турниры** в профиле. Запишитесь на доступное
   событие и проверьте личную историю и ближайшее событие на Главной.
5. Для своего открытого события измените условия с двух устройств, войдя в
   аккаунт организатора на обоих. На первом
   устройстве сохранение устаревшей версии должно сохранить черновик и
   предложить проверить актуальные условия. До выбора сохранение недоступно.
   Выберите «Продолжить с моим черновиком», исправьте текст и сохраните.
   Состав участников должен сохраниться; новое условие должно быть видно
   второму участнику.
6. Для обычного матча проверьте прежнюю схему четырёх подтверждений.
   Неподтверждённый результат и турнирные очки не должны менять обычный рейтинг.

## Сеть, удобство и push

- Через Алмател Wi-Fi без VPN, затем через МегаФон с выключенными Wi-Fi и VPN
  проверьте вход, профиль, изображения и сообщения. Одного открывающегося
  адреса проверки сервера недостаточно. Зафиксируйте сеть и время отказа.
- Во время отправки переключитесь между Wi-Fi и мобильной сетью. После
  восстановления соединения повторите неподтверждённое действие: дубликат
  сообщения или результата появляться не должен.
- Включите очень крупный системный текст, VoiceOver и «Уменьшение движения».
  Проверьте подписи, прокрутку, выбор иконок, открытие и закрытие окон,
  доступность кнопок при открытой клавиатуре и плавность переходов.
- Проверку push проводить только после отдельного подключения Apple и
  серверной отправки. Проверить доставку при закрытом приложении, открытие
  нужного события по нажатию, выключение уведомлений и выход из аккаунта.
  В текущем кандидате удалённые push выключены; их доставка не подтверждена.

| Проверка | Результат, сеть и время |
|---|---|
| Лайм → Графит → Мяч → Лайм и перезапуск | Не проверено |
| Темы и системное оформление иконок | Не проверено |
| Сохранность прежнего аккаунта и истории | Не проверено |
| Сообщения, новости, события и конфликт правок | Не проверено |
| Алмател Wi-Fi без VPN, полный сценарий | Не проверено |
| МегаФон без VPN, полный сценарий | Не проверено |
| Крупный текст, VoiceOver, уменьшение движения | Не проверено |
| Push после подключения | Не проверено |
