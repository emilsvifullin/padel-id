# Доказательства локальных проверок 1.1.0

`1.1.0-local-checks.json` сохраняет отобранные итоговые строки фактических логов, SHA256 оригиналов и сводку unit xcresult. Проверки выполнены до смены режима среды в отдельной Developer-копии; исходники перенесены в текущую рабочую копию с проверкой SHA256 каждого файла. Это запись прежних результатов, а не новый прогон.

В JSON включены только разрешённые по шаблонам строки результатов; запросы, тела ответов, переменные окружения и секреты не копировались. Полные логи и xcresult остаются в `/tmp/padel-id-checks/`; временная папка может исчезнуть. SHA256 позволяет сверить сохранённый оригинал, но не заменяет его содержимое.

106 успешных unit-тестов включают параметризованный тест на 32 fixtures: xcresult считает 137 исполнений на устройстве. Social UI: 4 успешных теста после исправления маршрута. Home/Players: 3 успешных теста в предыдущем целевом прогоне; весь тот прогон не объявляется успешным. Smoke/full E2E используют разные режимы и пропускают неприменимые тесты. Release archive завершился ошибкой sandbox; IPA отсутствует.

Обязательные GitHub Actions, production-поставка и проверки физического iPhone остаются непроверенными. Состояние и следующие команды — в `../../HANDOFF.md`, порядок приёмки — в `../release-1.1.0.md`.
