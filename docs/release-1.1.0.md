CLI предварительной проверки и поставки (из корня репозитория, после успешных проверок и с действующим разрешением):

```sh
supabase db push --project-ref xnxhlfuncxyzdfdmqlkb --linked --dry-run --skip-vault

Это не основание отключать предусмотренные endpoints или объявлять весь production security audit чистым.

## Администрирование тренеров

Раздел виден только когда `GET /v1/me` возвращает `is_admin=true`; его отсутствие само по себе не доказывает ошибку интерфейса. Проверка назначения выполняется владельцем проекта в доверенной SQL-консоли, без ключей в приложении:

```sql
-- Сначала найдите существующий аккаунт; проверьте username/display_name.
select id, username, display_name, deleted_at
from public.profiles where username = 'нужное_имя';
-- Убедитесь, что ID совпадает с нужным существующим аккаунтом.
select user_id from private.admins where user_id = 'проверенный_uuid'::uuid;
-- Только отдельное осознанное назначение владельцем:
insert into private.admins(user_id) values ('проверенный_uuid'::uuid)
on conflict (user_id) do nothing;
```

Обновить данные/войти снова; `GET /v1/me` должен вернуть `is_admin=true`, «Профиль» → «Администрирование» → «Заявки тренеров» должен открыться. Второй обычный аккаунт получает отказ на `v1/admin/coach-applications`, даже при прямом запросе. Ни создание привилегированного аккаунта, ни назначение администратора не требуются для release и в этой поставке не выполняются.

## Реальный iPhone: воспроизводимый чек-лист

Записать iPhone/iOS/build, дату, оператора, Wi-Fi и VPN. В каждой реальной сети выполнить один и тот же сценарий и сохранить фактические результаты:

| Сеть | Физическое устройство и сеть | Результат |
|---|---|---|
| Wi-Fi без VPN | Требуется реальный iPhone | Не подтверждён автоматически |
| Wi-Fi с VPN | Требуются iPhone и включённый VPN | Не подтверждён автоматически |
| LTE без VPN | Отключить Wi-Fi, проверить реальный LTE | Не подтверждён автоматически |
| LTE с VPN | LTE и включённый VPN | Не подтверждён автоматически |

1. Войти существующим аккаунтом, загрузить профиль, друзей, анализ и матчи.
2. Отправить заявку второму аккаунту, принять/отклонить/отозвать; проверить одинаковую дружбу с обеих сторон. Скрытый профиль доступен только по описанным правилам, почта и настройки никогда не видны другим.
3. Создать будущую открытую игру, присоединиться надёжным аккаунтом, подать заявку предварительным, принять её организатором. Проверить свободные места и состав; два одновременных запроса на последнее место не создают пятого игрока. Отозвать заявку/участие и отменить отдельную игру.
4. После реальной игры внести результат из её карточки. Проверить четыре подтверждения, спор/исправление, обновление рейтинга только после полного согласия и совпадение формы/статистики.
5. Открыть редактирование профиля, выбрать/сменить фото нажатием на круг, проверить загрузку, ошибку, удаление и уникальность username. Два разных аккаунта не могут сохранить одинаковый username; display_name может совпадать.
6. Быстро переключать тип матча и периоды30/90/год/всё на iPhone17ProMax, проверяя правильные данные и отзывчивость; повторить с «Уменьшение движения», VoiceOver, крупным шрифтом и светлой/тёмной темами. Измерять frame pacing инструментами устройства; Mirroring не является доказательством.
7. Переключить Wi-Fi↔LTE, потерять/восстановить сеть во время отправки результата и подтверждения. Проверить outbox, повторную отправку с тем же ключом, отсутствие дублей. Дружба и бронирование мест требуют сети; сохранённые данные явно помечены. Повторить реальные VPN-сочетания.

Успешная сборка/симулятор/проверка с компьютера не заменяют эти пункты. Фактическая доступность и результаты сохраняются в HANDOFF.md.
