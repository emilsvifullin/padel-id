Первый выпуск Padel ID — паспорта падел-игрока для iPhone.

**Что внутри**
- Регистрация, вход, ключ восстановления, смена пароля и почты, удаление аккаунта.
- Уровень 0–7 с надёжностью: стартовая калибровка, пересчёт после каждого подтверждённого рейтингового матча с объяснением изменений.
- Padel DNA — шесть направлений стиля игры с уровнем доверия: самооценка, отзывы партнёров и соперников, оценки подтверждённых тренеров.
- Матчи 2×2: товарищеские и рейтинговые, проверка счёта по правилам падела, подтверждение всеми участниками, споры, работа без сети.
- Поиск игроков с фильтрами, профили, совместимость партнёров, анализ игры и статистика.
- Заявки тренеров и подтверждённые тренером навыки.

**Установка**
Скачайте `PadelID.ipa` ниже и установите через SideStore или iLoader (подпись вашим Apple ID). Контрольная сумма — в `PadelID.ipa.sha256`.

Это самостоятельная release-сборка: она работает с продакшен-сервером и не требует локальной среды разработки.
